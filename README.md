## 🧠 About This Repository

**Agentic-AI-Workshop** contains the code, exercises, and project files developed during my participation in the Agentic AI learning sessions on **Infosys Springboard**. 

While traditional AI models act as passive assistants (waiting for prompts), **Agentic AI** focuses on building autonomous agents that can plan, reason, use tools, and execute multi-step workflows to achieve complex goals. This repository serves as a hands-on exploration of those concepts.

### ✨ Core Concepts Covered
- **Agentic Workflows:** Moving beyond zero-shot prompting to iterative reasoning and planning.
- **Tool Use (Function Calling):** Enabling LLMs to interact with external APIs, databases, and environments.
- **Memory Management:** Implementing short-term and long-term memory for contextual awareness.
- **Multi-Agent Systems:** Coordinating multiple specialized AI agents to solve complex tasks.
